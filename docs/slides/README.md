# Slides del pitch

Abrí `index.html` con doble clic: es un solo archivo autocontenido y funciona offline.
Navegá con flechas, espacio, clic o swipe; `F` activa pantalla completa y `N` muestra/oculta las notas del orador. También podés abrir una slide directa con `#3` en la URL.
Para exportar: Ctrl+P → “Guardar como PDF”; el CSS de impresión genera una slide 16:9 por página, sin controles.
Antes de presentar, completá todos los marcadores visibles `[COMPLETAR: ...]`: QR, URL de Vercel, dato de validación y resultados de validación.
